# The Last Pack Club

Start Club work with [the short asset index](last-pack-club/ASSET_INDEX.md). Identify the approved video and existing files to reuse before creating assets or code. Then read last-pack-club/STYLE_GUIDE.md and last-pack-club/CHARACTERS.md before planning, drawing, generating or rendering. Inspect only references needed for the current scene, at their native aspect ratio. Read skills/directing-stickman-videos/SKILL.md and the B6 route for production. Apply the Club's explicit identity, audio, format and spend choices.

Preserve original references and previously approved artwork. Keep candidates separate in last-pack-club/previews and record approval only when the user grants it. For a new scene, create one representative preview frame first. Render a 540×960 draft with audio for timing review. Render the final 1080×1920 video after user approval.

Use approved videos as production templates. Reuse character art, backgrounds, props, animation functions, caption styles, sound effects and export settings. Generate artwork only for missing poses, props or settings. Reinstall working dependencies, repeat successful diagnostics, scan the whole repository or regenerate approved assets only when a specific problem requires it.

For revisions, change only the requested elements and inspect the affected shots. Run broader checks only for changes that affect the whole video.

At completion, save editable source, the timeline and reusable assets. Update the short index with paths, descriptions and a brief production summary. Link to the timing source when the timeline lives in code. Keep progress reports focused on decisions and blockers.
