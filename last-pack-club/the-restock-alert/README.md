# THE RESTOCK ALERT

An 18-second Last Pack Club skit. The 540 frames are authored at 1080 × 1920 and 30 fps. Frames 538 and 539 are black.

## Edit and reproduce

From this directory in the prepared repository, run these commands.

```bash
/workspace/.stickman-venv/bin/python prepare.py
/workspace/.stickman-venv/bin/python sound.py
node scene.mjs still 41 representative.png
node scene.mjs
```

The final command replaces the local MP4. The director's installed Canvas runtime and Archivo Black font are loaded from the repository. FFmpeg performs the encode. The room plate and isolated expression base are reusable PNG assets. The original approved reference remains at ../references/frames/chase-standing.png. The face, cap and nose use reference pixels. The animated eyes, brows, mouth, hoodie, sleeves and arms are fitted to this seated shot. This is a shot-specific character construction.

The scene source contains the screen-local battle, wallpaper, open binder, slabs, sorting card, phone UI and movement tracks. Shot changes crop the same coordinate space. The source WAV contains the effects-only timeline. Both notifications reuse the same synthesized sample. Frame 45 starts the first alert, frame 270 starts the first sold-out hold and frame 294 starts the repeated notification. The taps occur at 4.30, 14.05, 14.25 and 14.45 seconds; the second sold-out result starts at 15.30 seconds. The last caption spans frames 495–537.
